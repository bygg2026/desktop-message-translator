# Desktop Message Translator

[简体中文](README.zh-CN.md)

Unofficial Signal Desktop derivative with automatic bidirectional translation.

## Features

- Incoming message translation
- Outgoing message translation
- First Enter: translate and preview
- Second Enter: send translated text
- Google Translate mode
- DeepL API support
- OpenAI-compatible custom API
- Automatic model discovery
- API verification before use
- Custom outgoing AI style
- Translation failure protection

## Privacy

Messages translated through external services are sent in plaintext to the selected translation provider.
