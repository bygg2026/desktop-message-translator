# Desktop Message Translator

[English](README.md)

基于 Signal Desktop 开源代码修改的非官方双向自动翻译桌面客户端。

## 功能

- 接收消息自动翻译
- 发送消息自动翻译
- 第一次 Enter：翻译并预览
- 第二次 Enter：正式发送
- Google 免费翻译模式
- DeepL API
- 自定义 OpenAI-compatible API
- 自动获取模型
- API 验证成功后才能使用
- 自定义 AI 发送语气
- 翻译失败时禁止原文误发

## 隐私

使用外部翻译服务时，需要翻译的消息明文会发送给所选择的翻译服务商。
